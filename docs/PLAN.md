# 요금제와 프리미엄 기능

## 지금 구성

| 기능 | 무료 | 프리미엄 |
|---|---|---|
| 과제 검사 | 하루 2개 | 무제한 |
| 자료 노트북 (내 자료로만 답하는 질문·답변, 근거 문장 표시) | ✗ | ✓ |
| 시험 대비 팩 (요약 노트 · 예상 문제 · 암기 카드 · 개념 지도) | ✗ | ✓ |
| 1분 퀴즈 · 연속 학습 | ✓ | ✓ |

- 설정 위치: `js/plan.js` (`FREE_DAILY_FILES`, 가격 표시 `PRICE_LABEL`, 결제 연동 여부 `PAYMENT_READY`)
- 프리미엄 화면: `#/premium`, 자료 노트북: `#/notebook`
- 서버: `api/study.js` (Gemini, 자료 최대 10개 · 합계 60만 자 ≈ A4 300장)
- 과제 검사: 파일 100MB · 25만 자(A4 100장 이상)까지 AI 채점

> 기능 이름은 우리 서비스 고유 이름(자료 노트북, 시험 대비 팩)으로 지었어요. 비슷한 서비스(NotebookLM, 유니브AI)의 이름은 다른 회사 상표라 앱 안에서 쓰지 않는 게 안전해요.

## ⚠️ 실제 유료 출시 전에 꼭 할 일

지금은 **결제 연동 전 시연 단계**예요.

1. **프리미엄은 "체험 스위치"로 켜고 꺼요.** 실제 돈이 청구되지 않아요.
2. **무료 2회 제한과 프리미엄 여부가 사용자 브라우저에만 저장돼요.** 개발 도구로 쉽게 바꿀 수 있어서, 지금 상태로는 돈을 받으면 안 돼요.

출시하려면 아래가 필요해요.

| 할 일 | 추천 | 이유 |
|---|---|---|
| 로그인 | 카카오 로그인 / Google 로그인 | 사용자를 구분해야 사용량을 셀 수 있음 |
| 데이터베이스 | Vercel 마켓플레이스의 Supabase 또는 Neon | 사용량·결제 상태를 서버에 저장 |
| 결제 | 토스페이먼츠 (정기결제) | 국내 대학생 결제 수단 |
| 서버 검사 | `api/analyze.js`, `api/study.js`에서 로그인·결제 상태·오늘 사용량 확인 | 브라우저 조작으로 우회하지 못하게 |
| 약관·개인정보 | 이용약관, 개인정보 처리방침, 환불 규정 | 유료 서비스 필수. 과제 원문을 AI(구글)로 보낸다는 안내 포함 |
| Gemini 유료 요금제 | AI Studio의 a-flo 프로젝트에 결제 연결 | 무료 요금제는 보낸 글이 구글 제품 개선에 쓰임 |

결제가 연결되면 `js/plan.js`의 `PAYMENT_READY`를 `true`로 바꾸고, `js/views/premium.js`의 `// 결제 연동 시 여기서 결제창 호출` 자리에서 결제창을 띄우면 돼요.
