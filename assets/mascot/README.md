# 캐릭터 PNG 넣는 곳

디자인팀 PNG를 아래 이름 그대로 넣으면, 앱이 임시 그림 대신 자동으로 그 PNG를 써요. (코드 수정 필요 없음)

## 규격

- **600 × 600 px, 배경 투명 PNG**
- 캐릭터는 가운데, 사방 여백 약 8%
- 파일 이름은 **영어 소문자** 그대로

## 폴더 = 캐릭터

| 폴더 | 캐릭터 |
|---|---|
| `chick/` | 삐약이 (병아리) |
| `owl/` | 학점이 (올빼미) |
| `flame/` | 불씨 (불꽃 정령) |
| `a/` | 에이 (로고 A) |

## 파일 이름 = 장면 (캐릭터마다 9장)

| 파일 이름 | 장면 | 앱에서 나오는 곳 |
|---|---|---|
| `default.png` | 기본 | 여러 곳 |
| `quiz.png` | 퀴즈 출제 (안경 치켜올리며 윙크) | 홈, 퀴즈 시작 |
| `analyzing.png` | 돋보기 들고 서류 뒤적이기 | 분석 대기 화면 |
| `danger.png` | 식은땀 흘리며 당황 | 결과에 🔴 위험이 있을 때 |
| `cheer.png` | 학사모 던지며 환호 | A+ 유력, 퀴즈 정답 |
| `sad.png` | 불꽃 끊김 (눈물) | 연속 학습이 끊겼을 때 |
| `lv1.png` | 성장 1단계 | 연속 0~2일 |
| `lv2.png` | 성장 2단계 | 연속 3~13일 |
| `lv3.png` | 성장 3단계 | 연속 14일 이상 |

예: 삐약이 퀴즈 장면 → `assets/mascot/chick/quiz.png`

참고 시안은 Figma 「에이플로 캐릭터 시안」 파일에 있어요.
