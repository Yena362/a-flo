# Firebase 연동 안내

Google 로그인과 기록 백업을 Firebase로 처리해요. **로그인하지 않아도 앱은 지금처럼 기기(localStorage)에만 저장하며 동작해요.** 로그인하면 연속 학습·다이아·경험치·검사 기록이 내 계정에 백업되고, 다른 기기에서도 이어져요.

Firebase 프로젝트 ID: `a-flo-e02b3`

## 1. 처음 한 번: Firebase 콘솔 설정

1. **웹 앱 등록**: 프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹 앱(`</>`). 나오는 `firebaseConfig` 값이 `js/firebase-config.js`에 들어 있어야 해요. (현재 채워져 있어요. 값이 바뀌면 여기를 고치세요.)
2. **로그인 켜기**: Authentication → 시작하기 → 로그인 방법 → **Google** 사용 설정.
3. **승인된 도메인 추가**: Authentication → 설정 → 승인된 도메인에 `a-flo.vercel.app` 추가. (`localhost`는 기본으로 들어 있어요.) 미리보기 배포 주소(`*.vercel.app`)에서 시험하려면 그 주소도 추가해야 해요.
4. **데이터베이스 만들기**: Firestore Database → 데이터베이스 만들기 (프로덕션 모드, 서울 `asia-northeast3` 추천).
5. **보안 규칙 적용**: Firestore → 규칙 탭에 이 저장소의 `firestore.rules` 내용을 붙여넣고 게시. (본인 문서만 읽고 쓸 수 있어요.)

## 2. 화면에는 어떻게 붙어 있나요

- **마이 탭(`js/views/my.js`)** 에 "기록 백업" 카드가 있어요. 로그아웃 상태에서는 `Google로 로그인` 버튼, 로그인 상태에서는 이름·이메일과 `로그아웃` 버튼이 보여요. 설정값이 비어 있으면 카드 자체가 숨겨져요.
- **앱 시작(`js/app.js`)** 에서 `initCloud()`를 한 번 불러요. 로그인 상태가 바뀌거나 클라우드 기록을 받아오면 마이·퀴즈·프리미엄 화면만 다시 그려요. 과제를 검사하거나 교정하는 중인 화면은 건드리지 않아요.
- **"모든 기록 초기화"** 는 로그인 중이면 클라우드 백업도 함께 지워요. (안 그러면 다시 로그인할 때 기록이 되살아나요.)
- Firebase 코드는 용량이 커서 **로그인한 적 있는 기기에서만 앱 시작 때 불러오고**, 처음 쓰는 기기에서는 로그인 버튼을 누를 때 불러와요. 로그인 안 쓰는 사람의 시작 속도는 그대로예요.

다른 화면에서 로그인 상태가 필요하면:

```js
import { getUser, signIn, signOut } from './js/cloud.js';

getUser();   // null(로그아웃) 또는 { uid, name, email, photo }
signIn();    // Google 로그인 팝업
signOut();   // 로그아웃 (기기에 있는 기록은 그대로 남아요)
```

기록을 바꾸는 코드는 기존처럼 `store.set()`, `recordCorrect()`, `addHistory()`만 쓰면 돼요. 로그인 중이면 바뀐 뒤 약 1.5초 뒤에 자동으로 클라우드에 올라가요.

## 3. 어떻게 저장되나요

- 위치: Firestore `users/{내 uid}` 문서 하나에 `state`로 저장
- 올라가는 것: 연속 학습, 최고 연속, 경험치, 다이아, 검사권, 오늘 검사 횟수, 검사 기록(최근 20개), 오늘의 퀴즈·보상 기록, 마스코트
- **안 올라가는 것**
  - 과제 원문(`draft`): 크고 개인적이라 기기에만 둬요.
  - 요금제(`plan`): 지금은 시연용 체험 스위치라 계정에 묶지 않아요. 실제 결제를 붙일 때는 서버에서 관리해야 해요. (브라우저에서 고칠 수 있는 값을 계정에 저장하면 안전하지 않아요.)
  - 자료 노트북(`js/study.js`)의 자료·대화 기록: 지금은 기기에만 저장돼요.
- 로그인 직후 합치기 규칙은 `js/merge.js` 위쪽 주석 참고. 더 최근에 바뀐 쪽을 따르고, 최고 연속·경험치는 큰 값, 검사 기록·퀴즈 기록은 합쳐요.

> **알아두세요**: 지금 점수 관련 값(다이아·경험치·검사권 등)은 원래도 브라우저에서 고칠 수 있는 값이에요. 계정에 백업해도 그 점은 달라지지 않아요. 이 값들이 돈이나 혜택과 직접 연결되면 서버 검증이 필요해요.

## 4. 확인하기

```bash
npm test      # 합치기 규칙 포함, 모두 ok면 정상
npm start     # 로컬 화면 확인용 서버 (http://localhost:8080)
```

실제 로그인은 설정값과 콘솔 설정이 있어야 해서 자동 테스트에 넣지 않았어요. 아래 순서로 직접 확인해 주세요.

1. 마이 탭에서 `Google로 로그인`
2. Firebase 콘솔 Firestore에 `users/...` 문서가 생기는지 확인
3. 다른 브라우저(또는 시크릿 창)에서 같은 계정으로 로그인했을 때 기록이 이어지는지 확인

로그인이 안 될 때 흔한 원인: 승인된 도메인 누락(`auth/unauthorized-domain`), Google 로그인 미사용 설정(`auth/operation-not-allowed`), 팝업 차단(`auth/popup-blocked`).
